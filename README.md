## 🚧 Currently building

### [Mewgenics CatManager](https://github.com/mylabz-xyz/Mewgenics-CatManager)

A **native C++ mod for Mewgenics**, currently in development.

The project focuses on:

* reverse-engineering and parsing game save data;
* SQLite / LZ4 data processing;
* cat and pedigree reconstruction;
* inbreeding analysis;
* native DLL integration;
* runtime in-game UI integration.

> **Status: In Progress**
